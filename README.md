# Презентация: Теория графов

## Задание
- Презентация должна быть выполнена с помощью Markdown, где это возможно.
- Презентация должна быть выполнена с помощью фреймворка Reveal.JS.
- Тема (оформление) обязательно должна быть вынесена в отдельный CSS файл.
- Минимальное количество слайдов: 20.
- Перед каждым разделом необходимо использовать слайд-разделитель.
- Оформление презентации должно быть читаемым.
- Обязательными являются титульный слайд, заключительный слайд.
- Обязательно наличие меню для быстрого перехода к слайду, используя плагин reveal.js-menu. Меню должно быть рабочим. Все слайды должны иметь наименование в меню.
- Обязательно наличие навигации: стрелки, номер слайда.
- Обязательно наличие readme в корне презентации с заданием без указания баллов.
- В случае сомнения самостоятельности выполнения работы - требуется обоснования спорных мест.
- На слайде не должно быть скроллов.
- Минимальное количество изображений в презентации - 3.
- После создания репозитория - запрещается его удалять и перезаливать презентацию в новый репозиторий.
- Необходимо использовать локальную версию фреймворка Reveal.js.

## Обязательные слайды
- Определение теории графов. Что изучает, где применяется.
- Задача о 7 мостах (Формулировка, решение).
- Любой алгоритм поиска кратчайшего пути на графах.
- Программа на JavaScript для поиска пути по ортодромам между столицами регионов России с использованием карт. Вход: любые 2 города. Выход: карта с ортодромой и расстояние в км.
- Исходный код программы.
- При наличии оставшихся слайдов (не менее 3) — заполнить весёлыми картинками по теме.

## Структура проекта
- `index.html` — основной файл презентации
- `markdown/` — содержимое слайдов в формате Markdown
- `dist/` — локальные файлы фреймворка Reveal.js,Leaflet и KaTeX
- `plugin/` — плагины Reveal.js (menu, markdown, highlight, notes, zoom)
- `csv/cities.js` — база данных городов России
- `img/` — изображения для слайдов

## Запуск
1. Убедитесь, что все зависимости размещены локально.
2. Откройте `index.html` через локальный сервер (Live Server, Python http.server и т.д.).
3. Навигация: стрелки клавиатуры, кнопки на экране, меню по клавише `M`.
