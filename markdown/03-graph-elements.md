# Основные элементы графа

| Элемент | Описание | Пример в географии |
|---------|----------|-------------------|
| Вершина | Узел сети | Город |
| Ребро   | Связь | Автодорога или ж/д путь |
| Путь    | Цепочка рёбер | Маршрут из A в B |
| Цикл    | Путь, начинающийся и заканчивающийся в одной вершине | Кольцевая дорога |

Графы классифицируются по направлению рёбер и наличию весов.
