# Типы графов

- **Неориентированный** — связи двусторонние (дороги без одностороннего движения)
- **Ориентированный** — связи имеют направление (реки, потоки данных)
- **Взвешенный** — рёбрам присвоены числовые значения (расстояние, время, стоимость)
- **Дерево** — связный граф без циклов (иерархия регионов)
