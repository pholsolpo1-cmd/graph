# Обход графа.

- **Поиск в ширину** — посещает все соседние вершины, затем их соседей
  - Использует очередь
  - Находит кратчайший путь в невзвешенном графе
- **Поиск в глубину** — идёт максимально далеко по одной ветви, затем возвращается
  - Использует стек или рекурсию
  - Применяется для поиска циклов и топологической сортировки

Оба алгоритма имеют сложность $$O(V+E)$$.
