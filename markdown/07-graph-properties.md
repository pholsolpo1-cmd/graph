# Свойства графов

- **Степень вершины** — количество рёбер, инцидентных данной вершине
- **Связный граф** — между любыми двумя вершинами существует хотя бы один путь
- **Компонента связности** — максимальный связный подграф
- **Мост** — ребро, удаление которого увеличивает число компонент связности
- **Цикл** — замкнутый путь, где начальная и конечная вершины совпадают

Эти характеристики определяют устойчивость сети и возможность маршрутизации.
