# Географические графы

Транспортная система страны — это взвешенный неориентированный граф:
- **Вершины** — города, узловые станции, аэропорты
- **Рёбра** — автомобильные дороги, ж/д пути, авиамаршруты
- **Веса** — расстояние, время в пути, пропускная способность

Такая модель позволяет решать задачи логистики, планирования инфраструктуры и анализа связности регионов.
