# Анализ сетевых структур

Метрики, используемые для оценки графов:
- **Кратчайший путь** — минимальное расстояние между узлами
- **Диаметр графа** — максимальный из кратчайших путей
- **Коэффициент кластеризации** — плотность связей внутри групп
- **Центральность** — выявление ключевых узлов сети

Эти показатели позволяют находить узкие места, оптимизировать маршруты и повышать отказоустойчивость систем.
